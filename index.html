¡Hola! Soy Carlos Alberto Castro 👋

Soy un desarrollador de software apasionado, de Yumbo, Valle del Cauca, estudiante de la Universidad del Valle. Llevo más de 2 años trabajando con tecnologías como React, Django y Flutter, construyendo aplicaciones web y móviles que resuelven problemas reales.

Mi filosofía de trabajo se centra en escribir código limpio, eficiente y mantenible. Disfruto trabajar con tecnologías como React, Django y Flutter para construir soluciones completas de principio a fin.

Cuando no estoy programando, me gusta explorar nuevas tecnologías, aprender constantemente y contribuir a proyectos que generen impacto positivo en la comunidad.

🎯 Orientado a resultados 🤝 Trabajo en equipo 📚 Aprendizaje continuo 💡 Pensamiento creativo

Mis proyectos

Algunas cosas que he construido

🏥
Mobile + API

MedConnect ⭐

Aplicación médica móvil que conecta pacientes y profesionales de la salud. Permite agendar citas, consultar historiales clínicos y visualizar relaciones entre datos médicos mediante grafos. Desarrollada con Flutter (frontend mobile) y Python (backend con algoritmos de grafos).

Flutter Dart Python FastAPI Grafos
🎓
Full Stack Web

Profesores Rating

Plataforma web para calificar y consultar reseñas de profesores universitarios. Incluye sistema de autenticación con JWT, manejo de sesiones seguras con bcrypt y una interfaz dinámica en Angular. Backend RESTful con Express y SQLite.

Angular TypeScript Node.js Express SQLite JWT
🏡
Full Stack Web

La Querencia

Plataforma web con sistema de invitaciones por token para gestión de comunidad. Implementa tokens de invitación seguros con expiración, roles de usuario (administrador/normal), notificaciones por email y CRUD completo de recursos. Arquitectura Django REST + React + Vite.

React Vite Django Django REST PostgreSQL Python
📅
Full Stack Web

OrEven — Organizador de Eventos

Aplicación para gestión logística de eventos con control de tareas por prioridad (Normal, Alta, Crítica) y estados (Pendiente, En Progreso, Hecho, Pospuesto). Gestiona límites de horas diarias por evento e integra IA con Google Gemini. Backend en Django con PostgreSQL y frontend en React + React Router.

React React Router Django Django REST PostgreSQL Google Gemini
